# Hermes Trader — Live Dashboard

Read-only dashboard for the Hermes Trader autonomous trading bot.

- `index.html` — the dashboard (dark trading terminal UI)
- `data.json` — latest bot snapshot, refreshed every few minutes by the bot
- This repo contains **no keys, no credentials, no code** — only the dashboard UI and its data snapshot.

## Status meanings
- **RUNNING / PAUSED / STOPPED** — the bot's trading state
- **LIVE / PAPER** — whether real money trades happen
- **SNAPSHOT badge** — when the page was last updated by the bot (UTC)
